# MMS 171: Personal Profile Page 🚀

This repository contains files for **MMS 171: Text in Multimedia** at the University of the Philippines Open University (UPOU). It tracks the progressive development of my personal "About Me" profile page from basic wireframing to a fully styled and deployed website.

## 🛠️ Tech Stack & Tools
* **HTML5:** Semantic structuring and content layout (`<header>`, `<main>`, `<section>`, `<footer>`).
* **CSS3:** *(Upcoming in Unit 3)* Styling, visual hierarchy, and responsive design.
* **Typography:** Google Fonts (Inter for Headings, Raleway for Body Text).
* **Deployment:** GitHub Pages.

- [x] **Unit 1 (Module 2):** Text in Action - Wireframing, typography planning, and layout sketching.
- [x] **Unit 2 (Module 3):** HTML Basics - Giving text structure (Semantic HTML).
- [ ] **Unit 2 (Modules 4-5):** XHTML, HTML5, and Metalanguages.

- [ ] **Unit 4 (Weeks 8-10):** Putting It All Together - Final polishing, integrating knowledge checks, and live deployment.
